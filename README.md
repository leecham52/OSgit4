# 오픈소스SW 과제 4

한 학기 동안 정신 없이 학교를 다니다 보면, 미처 생각지 못하게 바탕화면이 꽉찬다거나, 특정 폴더가 요리조리 꽉차는 경험을 한 적이 여러번 있습니다.
그때마다 파일을 하나하나 보면서 지우거나 다른 폴더로 옮기는 시간을 소모를 해야했던 걸 바탕으로

폴더 내 파일 자동 정리 프로그램을 만들었습니다.

- 기본적으로 글로벌변수로 바탕화면을 지정을 해뒀습니다만, 제 컴퓨터의 바탕화면이기 때문에, 이는 재정의해줄 필요가 있습니다. 혹은 다른 폴더를 지정해줘도 괜찮습니다.

코드 위에도 써뒀지만, 간단하게 프로그램의 작동 순서를 보자면,
0. 코드 실행
1. 자동으로 바탕화면 내의 폴더들의 이름을 터미널에 보여줌
2. 그 중 정리를 원하는 폴더의 명을 input으로 적으면
3. 그 폴더 내의 파일들과 폴더들을 리스트에 저장해주면서, 터미널에 출력
4. 안에 있는 파일들의 확장자를 보고, 있는 확장자들만 폴더 생성후 파일들 정리
5. 프로그램 종료
input 한번만 넣어주면 자동으로 처리가 끝나게 됩니다.

폴더 내에 있는 파일들의 확장자(. 뒤에 있는 단어들)을 미리 매핑해둔 후, 정리하는 방식을 택했습니다.
